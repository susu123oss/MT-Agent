**MT 智能体**把 AI 对话、项目管理、代码辅助、文件处理和问题排查带到 iPhone。你可以围绕一个项目持续交流，让 AI 从理解问题开始，协助推进后续工作。

## 主要功能

### 💬 智能对话与多任务协作
- 围绕同一问题连续对话，持续推进任务。
- 结合当前工作区和文件理解你的需求。
- 支持多任务与子代理协作，并清晰展示处理进度。

### 📁 项目与文件处理
- 创建、打开、整理项目工作区。
- 阅读、搜索与修改可访问的项目文件。
- 处理附件、长文本、日志及常见开发资料。

### 🧑‍💻 编程与问题分析
- 理解和修改代码，辅助改善已有功能。
- 分析异常日志、报错与构建问题。
- 根据设备可用功能协助执行任务并检查结果。
- 在具备条件时，可与 MT 内存工具配合开展真机分析。

### 📱 更自然的手机体验
- 适合触屏操作的聊天、工作区与附件界面。
- 支持官方账号登录及兼容的第三方 AI 服务。
- 可查看任务状态、使用情况与相关功能入口。

## 使用场景

| 你想做什么 | 可以这样告诉 MT 智能体 |
| --- | --- |
| 了解项目 | “介绍一下这个项目的主要功能。” |
| 排查问题 | “分析这份闪退日志里的异常。” |
| 修改功能 | “检查相关文件，协助完成修改。” |
| 整理资料 | “把这些记录总结成重点。” |
| 持续处理任务 | “根据刚才的结果继续完成。” |

实际操作能力取决于 AI 服务、设备环境及已启用功能。
